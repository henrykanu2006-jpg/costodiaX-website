# CostodiaX Website

The marketing site for CostodiaX Group, built with Next.js, TypeScript and Tailwind CSS.

## Pages
- Home (`/`)
- Services (`/services`)
- Voya Platform (`/voya`)
- About (`/about`)
- Contact (`/contact`)
- Privacy Policy (`/privacy`)

## Development

```bash
npm install
npm run dev
```
